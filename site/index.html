    FAQ

    Коротко о важном.

    Это обновление через Google Play?

    Нет. APK будут размещаться в GitHub Releases; установку или обновление подтвердит штатный установщик Android.

    Почему Android спрашивает разрешение на установку?

    Для приложений, установленных не из официального магазина, Android требует отдельное разрешение для источника установки. Это нормальная системная защита.

    Потеряются ли книги после обновления?

    При обновлении того же приложения с той же подписью данные обычно сохраняются. Перед выпуском мы проверим это на телефоне; при переходе с тестовой подписи на будущую постоянную может понадобиться отдельная миграция.

    Какие форматы поддерживаются?

    Базовый набор: EPUB, FB2/FB2.ZIP и PDF, плюс аудиокниги.

    Где посмотреть номер версии?

    Номер установленной версии Android показывает в сведениях о приложении. Проверка обновлений в настройках PluriBooks появится вместе с обновляющим модулем.
